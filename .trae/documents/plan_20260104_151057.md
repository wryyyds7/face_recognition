# 人脸检测结果返回优化实现计划

## 1. 需求分析

用户希望通过int类型标识不同的人脸检测情况，并返回相应的结果：

| 情况           | 返回结果           |
| ------------ | -------------- |
| 正确识别到人脸并且匹配  | 返回名字（文件名去掉后缀）  |
| 正确识别到人脸但是不匹配 | "检测到人脸但不在数据库中" |
| 未识别人脸        | "没有检测到人脸"      |
| 未知状态         | "未知的验证状态"      |
| 失败           | "实时人脸检测失败"     |

## 2. 实现步骤

### 2.1 修改服务层接口和实现

#### 2.1.1 修改 `FaceDetectionService` 接口

* 保持 `realTimeFaceDetection()` 方法返回 `int` 类型，用于标识不同情况

* 保持 `verifyFace(String imgPath)` 方法返回 `Map<String, Object>`，用于返回详细结果

#### 2.1.2 修改 `FaceDetectionServiceImpl` 实现类

* 完善 `realTimeFaceDetection()` 方法，返回正确的 int 值：

  * 1：正确识别到人脸并且匹配

  * 2：正确识别到人脸但是不匹配

  * 3：未识别人脸

  * 4：未知状态

  * 5：失败

* 在 `handleVerificationResult()` 方法中添加逻辑，保存识别到的名字

* 修改 `verifyFace()` 方法，确保返回的 Map 包含完整的状态信息

### 2.2 修改控制器层

#### 2.2.1 修改 `FaceRecognitionController`

* 修改 `manualDetect()` 方法，根据 `realTimeFaceDetection()` 返回的 int 值返回不同结果：

  * 1：返回包含名字的成功结果

  * 2：返回 "检测到人脸但不在数据库中"的成功结果

  * 3：返回 "没有检测到人脸"的成功结果

  * 4：返回 结果信息为"未知的验证状态，请联系管理员或者重试"

  * 5：返回 返回结果信息为"实时人脸检测失败，请联系管理员或者重试"

* 修改 `verifyFace()` 方法，根据返回的 Map 中的状态返回不同结果：

  * "recognized"：返回包含名字的成功结果

  * "unknown\_face"：返回 "检测到人脸但不在数据库中"

  * "no\_face"：返回 "没有检测到人脸"

  * 其他：返回 "未知的验证状态"

* 修改 `recognizeFace()` 方法，保持与 `verifyFace()` 方法的一致性

### 2.3 实现辅助方法

* 在 `FaceDetectionServiceImpl` 中添加辅助方法 `extractNameFromPath()`，用于从文件路径中提取名字（去掉后缀）

* 在 `handleVerificationResult()` 中保存识别到的名字，以便 `realTimeFaceDetection()` 方法返回

## 3. 代码修改点

### 3.1 `FaceDetectionServiceImpl.java`

* 修改 `realTimeFaceDetection()` 方法，返回 int 值

* 修改 `handleVerificationResult()` 方法，保存识别到的名字

* 添加 `extractNameFromPath()` 辅助方法

### 3.2 `FaceRecognitionController.java`

* 修改 `manualDetect()` 方法，根据 int 值返回不同结果

* 修改 `verifyFace()` 方法，根据状态返回不同结果

* 修改 `recognizeFace()` 方法，保持一致性

## 4. 预期结果

* 自动检测和手动检测都能返回正确的结果

* 正确识别到人脸并且匹配时，返回包含名字的结果

* 正确识别到人脸但是不匹配时，返回 "检测到人脸但不在数据库中"

* 未识别人脸时，返回 "没有检测到人脸"

* 未知状态时，返回 "未知的验证状态"

* 失败时，返回 "实时人脸检测失败"

## 5. 注意事项

* 确保自动检测和手动检测的逻辑一致

* 确保返回结果的格式统一

* 确保从文件路径中正确提取名字

* 确保异常处理完整
