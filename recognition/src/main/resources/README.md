# 人脸识别服务API文档

## 1. 概述

人脸识别服务提供人脸检测、识别、考勤打卡等功能。

## 2. API地址

- Swagger UI地址：http://localhost:{port}/swagger-ui.html
- API文档JSON：http://localhost:{port}/v2/api-docs

## 3. 主要功能模块

### 3.1 人脸识别管理

- 手动触发实时人脸检测
- 人脸验证
- 人脸识别
- 为用户添加人脸照片
- 批量为用户添加人脸照片
- 更新用户人脸照片
- 删除用户人脸照片
- 获取用户的人脸照片列表
- 根据用户名获取用户的人脸照片列表
- 清空用户的所有人脸照片

### 3.2 自动检测管理

- 开启自动检测
- 停止自动检测
- 获取自动检测状态
- 开启识别结果保存
- 关闭识别结果保存

### 3.3 打卡管理

- 手动打卡
- 根据用户ID查询打卡记录
- 根据时间范围查询打卡记录
- 获取打卡统计数据

### 3.4 识别日志管理

- 获取识别日志列表
- 根据日志ID获取识别日志

## 4. 使用说明

1. 启动人脸识别服务
2. 访问Swagger UI地址查看完整的API文档
3. 使用API测试工具（如Postman）调用API接口
4. 查看控制台日志了解API调用情况

## 5. 注意事项

- 调用API前请确保已获取有效的Token
- 人脸照片上传时请确保照片质量良好
- 自动检测功能会消耗较多系统资源，请合理使用
