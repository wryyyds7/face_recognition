# 用户服务API文档

## 1. 模块概述
用户服务提供用户管理、投诉管理等功能。

## 2. 接口列表

### 2.1 用户管理接口

#### 2.1.1 用户搜索服务(分页)
- **接口路径**：/users/admin/searchUserByPage
- **请求方法**：POST
- **功能描述**：分页搜索用户
- **请求参数**：
  - pageNum：页码（Integer类型）
  - pageSize：每页条数（Integer类型）
  - userName：用户名（String类型，可选）
  - email：邮箱（String类型，可选）
  - phone：手机号（String类型，可选）
- **响应结果**：
  - total：总记录数
  - list：用户列表
  - pageNum：当前页码
  - pageSize：每页条数
- **使用示例**：
  ```
  POST /users/admin/searchUserByPage
  Content-Type: application/json
  
  {
    "pageNum": 1,
    "pageSize": 10,
    "userName": "admin"
  }
  ```
- **返回示例**：
  ```json
  {
    "code": 200,
    "message": "操作成功",
    "data": {
      "total": 1,
      "list": [
        {
          "userId": 1,
          "userName": "admin",
          "email": "admin@example.com",
          "phone": "13800138000",
          "status": "ACTIVE",
          "roles": ["ADMIN"]
        }
      ],
      "pageNum": 1,
      "pageSize": 10
    }
  }
  ```

### 2.2 投诉管理接口

#### 2.2.1 创建投诉
- **接口路径**：/users/complaint
- **请求方法**：POST
- **功能描述**：创建投诉
- **请求参数**：
  - title：投诉标题（String类型）
  - content：投诉内容（String类型）
  - userId：用户ID（Long类型）
  - complaintType：投诉类型（String类型）
- **响应结果**：
  - complaintId：投诉ID
- **使用示例**：
  ```
  POST /users/complaint
  Content-Type: application/json
  
  {
    "title": "系统故障",
    "content": "系统无法正常登录",
    "userId": 1,
    "complaintType": "SYSTEM"
  }
  ```
- **返回示例**：
  ```json
  {
    "code": 200,
    "message": "操作成功",
    "data": 1
  }
  ```

#### 2.2.2 获取投诉列表
- **接口路径**：/users/complaint/list
- **请求方法**：GET
- **功能描述**：获取投诉列表
- **请求参数**：
  - title：投诉标题（String类型，可选）
  - complaintType：投诉类型（String类型，可选）
  - status：投诉状态（String类型，可选）
- **响应结果**：
  - 投诉列表
- **使用示例**：
  ```
  GET /users/complaint/list?status=PENDING
  Content-Type: application/json
  ```
- **返回示例**：
  ```json
  {
    "code": 200,
    "message": "操作成功",
    "data": [
      {
        "complaintId": 1,
        "title": "系统故障",
        "content": "系统无法正常登录",
        "userId": 1,
        "userName": "admin",
        "complaintType": "SYSTEM",
        "status": "PENDING",
        "createTime": "2026-01-06 10:00:00"
      }
    ]
  }
  ```

#### 2.2.5 处理投诉
- **接口路径**：/users/complaint/handle/{complaintId}

#### 2.2.7 上传投诉附件
- **接口路径**：/users/complaint/attachment
- **请求方法**：POST
- **功能描述**：上传投诉附件
- **请求参数**：
  - complaintId：投诉ID（Long类型）
  - fileName：文件名（String类型）
  - filePath：文件路径（String类型）

- **使用示例**：
  ```

    "filePath": "/upload/2026/01/06/screenshot.png",

  }
  ```
- **返回示例**：
  ```json
  {
    "code": 200,
    "message": "操作成功",

  }
  ```
