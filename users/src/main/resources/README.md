# 用户服务API文档

## 1. 概述

用户服务提供用户管理、投诉管理等功能。

## 2. API地址

- Swagger UI地址：http://localhost:{port}/swagger-ui.html
- API文档JSON：http://localhost:{port}/v2/api-docs

## 3. 主要功能模块

### 3.1 用户管理

- 用户搜索服务(分页)
- 用户搜索服务
- 用户删除服务
- 用户删除服务(通过路径参数)
- 用户更新服务
- 用户状态更新服务
- 用户添加服务

### 3.2 投诉管理

- 创建投诉
- 获取投诉列表
- 获取投诉详情
- 更新投诉状态
- 处理投诉
- 获取用户的投诉列表
- 上传投诉附件
- 获取投诉附件列表

## 4. 使用说明

1. 启动用户服务
2. 访问Swagger UI地址查看完整的API文档
3. 使用API测试工具（如Postman）调用API接口
4. 查看控制台日志了解API调用情况

## 5. 注意事项

- 调用API前请确保已获取有效的Token
- 管理员操作需要ADMIN角色权限
- 用户操作需要USER角色权限
- 投诉附件上传时请确保文件格式正确
